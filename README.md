# High Altitude Solutions

Professional bucket truck services website built with Next.js.

## Services
- Tree trimming & pruning
- Signage installation
- Exterior building maintenance
- Custom height-access projects

## Location
Schenectady, NY — Serving the Capital Region

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Static files will be output to the `dist` directory.
